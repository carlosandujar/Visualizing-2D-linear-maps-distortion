# Visualizing 2D Linear Maps Distortion

An interactive browser app for exploring the distortion caused by a 2 × 2 matrix using a unit circle and a triangle. 

The app includes side-by-side **Original** and **Transformed** views to show how a 2D linear map stretches, rotates, reflects, or collapses shapes.

The app can support demonstrations and exercises in linear algebra and computer graphics. The author uses it in a geometry processing course to explain local distortion in mesh parameterization, including which maps preserve lengths, angles, or area and which reverse orientation.

## Using the app

1. Open [index.html](index.html) in a web browser. The app runs locally without installation.
2. Edit the matrix directly or choose a **Preset**, such as a rotation, reflection, or singular map. The transformed view updates as you make changes.
3. Drag either of the two circular vertex handles in **Original** or **Transformed** to update the matrix. The square vertex in each triangle is fixed at the origin.
4. The chips below the matrix indicate properties such as **Isometric**, **Angle-preserving**, **Area-preserving**, **Flip**, and **Singular**. The app also shows the singular values of the matrix, which indicate how much the map stretches or compresses in two orthogonal directions (i.e., the length of the semi-axes of the ellipse that is the image of the unit circle).

## Implementation details

The app is a single HTML file with embedded CSS and vanilla JavaScript. The Canvas 2D API is used to draw the shapes and vectors, and Pointer Events handle vertex dragging. 

A large part of the code was generated by Codex using GPT-6.1+ Sol, based on an earlier Three.js example by the author.

## Inspiration

The app is inspired by Chapter 4, “Linear Maps in 2D,” of Gerald Farin and Dianne Hansford’s *The Geometry Toolbox for Graphics and Modeling*. [Routledge book page](https://www.routledge.com/The-Geometry-Toolbox-for-Graphics-and-Modeling/Farin-Hansford/p/book/9780367447793)
